# Clash of Clans Management System

Object-oriented Java implementation of a Clash of Clans inspired management system featuring village building, troop training, clan systems, battles, persistence mechanisms, and UML-based software architecture.

---

## Features

- Building and upgrade system
- Troop and hero training
- Clan management
- Battle mechanics
- Save/load persistence
- GUI implementation
- UML-based architecture
- Dynamic analysis and design patterns

---

## Technologies Used

- Java
- JavaFX / Swing
- Serializable
- UML
- Git & GitHub

---

## System Architecture

```text
src/
 ├── models/
 ├── gui/
 ├── persistence/
 ├── services/
 ├── battles/
 ├── clans/
 └── main/
```
